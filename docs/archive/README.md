# Arquivo de Pacotes Concluídos

Registro histórico, **somente leitura**. Cada subpasta guarda o que foi concluído em uma versão:

| Pasta | Conteúdo |
| :--- | :--- |
| [`v1.0/`](v1.0/) | Backlog original (`PLANO_DESENVOLVIMENTO.md`) das FEAT-01 a FEAT-13 |

Ao concluir um pacote de `docs/changes/` (etapa **Arquivar** em `docs/README.md`), mova a pasta dele para `archive/<versão>/` (ex: `archive/v1.1/FEAT-14/`).
